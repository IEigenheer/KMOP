This repository contains a scientific paper written in LaTeX.

Rules:
- Never invent references.
- Never invent experimental results.
- Verify references before adding them.
- Add references to references.bib.
- Use \cite{} correctly.
- Maintain academic writing style.
- Preserve consistency between sections.
- Compile the LaTeX project after significant changes.
- Report compilation errors.
- Do not modify numerical results unless explicitly requested.

# References

- references.bib is automatically generated by Zotero + Better BibTeX.
- NEVER manually modify references.bib.
- Zotero is the source of truth for bibliographic references.
- Only cite references that exist in references.bib.
- Never invent citations, authors, titles, DOIs or publication data.
- Before citing a paper, verify that its citation key exists in references.bib.
- If a required reference is missing, tell the user instead of creating it.
